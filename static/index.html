      MethodThree extractors

      How a photograph becomes a neighbour

      The studio compares directions in a feature space. VGG19, DINOv2, and CLIP each keep their own index. Search can expand the query and check geometry before the list is shown.

      1. 01

        Image loading

        Photographs are collected from the library folder, including nested folders. Each file is checked as a real image before it is allowed into the set.

      2. 02

        Feature extraction

        VGG19 keeps its convolutional map and pools it with generalized mean pooling (GeM, p=3). The short side is resized to 256 and a 224 centre crop is taken, so the picture is not squashed. DINOv2 uses the class token concatenated with the mean patch token. The fine-tuned DINOv2 continues from that descriptor: the last two blocks and a 256-d projection were trained with triplet loss on the Caltech database only, leaving the queries out. CLIP uses the image tower of ViT-B/32, and the same space accepts a text query.

        • Early layersEdges and colour
        • Middle layersShapes and texture
        • Deeper layersObjects and scenes
      3. 03

        Normalization and whitening

        A horizontal flip is embedded too, the two vectors are averaged, and the result is scaled back to unit length. PCA whitening, fit on the database and kept at 256 dimensions, then removes the directions that dominate every photograph.

        v̂ = v / ‖v‖₂

      4. 04

        Indexing

        FAISS stores the unit vectors in an exact inner-product index (IndexFlatIP). On unit vectors that ranking matches Euclidean distance. Each model writes its own index, including the whitening that queries must reuse.

      5. 05

        Similarity matching

        The query takes the same extractor, flip, and whitening as the index. Optional alpha query expansion rebuilds the query as a weighted average of itself and its top neighbours. Optional geometric re-ranking checks the top 30 with ORB, a Lowe ratio test, and a RANSAC homography, then sorts by inlier count.

        similarity = 1 / (1 + distance)  ·  distance = √(2 − 2·cosine)

      6. 06

        Results

        Neighbours are shown closest first, with the similarity score, the raw distance, and a fingerprint of the feature vector. The map places the same vectors on a PCA plane so clusters are visible.

      Accuracy without training

      VGG19 is already trained on a large image set. The studio reuses that representation, so comparison does not need a dataset of labelled pairs.

      A manageable update

      New photographs are encoded and the index is rebuilt. Exact search over thousands of 512-d vectors stays practical on a laptop.

      Variation in the picture

      Because the vector describes shape, texture, colour, and arrangement, a match can survive changes in lighting, scale, and framing.
